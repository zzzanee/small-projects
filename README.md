# Small Projects

A collection of small projects maintained as Git submodules.

## Projects

- [stack-heap-c-sim](https://github.com/zzzanee/stack-heap-c-sim)

## Clone with projects

```sh
git clone --recurse-submodules https://github.com/zzzanee/small-projects.git
```

If you already cloned this repository:

```sh
git submodule update --init --recursive
```
